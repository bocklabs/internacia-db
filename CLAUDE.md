## Data access

Query `data/datasets/internacia.duckdb` or the Parquet exports, not the source YAML. They are generated, not committed: run `python scripts/builder.py build` once (or download them from the latest GitHub Release).

## Guardrails

- Countries are reference data only — do **not** add HDI, GDP, government type, or similar socioeconomic fields.
- Join intblocks on `includes[].id` (country alpha-2), not `includes[].name`.
- `borders` uses ISO alpha-3 codes; join on `iso3code`.
- Never hand-edit `data/datasets/` (generated by `python scripts/builder.py build`).
